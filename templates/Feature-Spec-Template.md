## 4. Requirements (ความต้องการของระบบ)

**Functional Requirements (ฟังก์ชันที่ต้องมี):**
* ผู้ใช้ต้องกรอกอีเมลที่สมัครไว้ในระบบเท่านั้น
* ระบบต้องส่งอีเมลพร้อมลิงก์ที่มีอายุการใช้งาน (Token) 15 นาที
* รหัสผ่านใหม่ต้องมีความยาวไม่น้อยกว่า 8 ตัวอักษร และมีตัวพิมพ์ใหญ่ผสม

**Non-Functional Requirements (ประสิทธิภาพและความปลอดภัย):**
* ระบบต้องรองรับการส่งอีเมลพร้อมกัน 1,000 ฉบับ/นาทีได้โดยไม่ดีเลย์
* ลิงก์ที่ถูกใช้งานไปแล้ว (หรือหมดอายุ) จะต้องไม่สามารถใช้งานซ้ำได้ (Security)

## 5. Technical Details (รายละเอียดทางเทคนิคสำหรับ Dev)

* **Frontend:**
  * สร้างหน้าจอใหม่ `/forgot-password` และ `/reset-password?token=xxx`
  * ใช้ Component `InputField` และ `Button` จาก Design System
* **Backend:**
  * สร้าง API ใหม่ 2 เส้น (อ้างอิงตาม API Reference)
    * `POST /api/v1/auth/forgot-password`
    * `POST /api/v1/auth/reset-password`
* **Database:**
  * เพิ่มตาราง (Table) `PasswordResetTokens` เพื่อเก็บ Token, UserID, และ ExpiryDate

## 6. Acceptance Criteria (เกณฑ์การตรวจรับงานสำหรับ QA)
รูปแบบ: Given [เงื่อนไขเริ่มต้น], When [กระทำบางอย่าง], Then [ผลลัพธ์ที่ต้องเกิดขึ้น]

* **Scenario 1: กรอกอีเมลถูกต้อง**
  * **Given:** ผู้ใช้อยู่ที่หน้า ลืมรหัสผ่าน
  * **When:** กรอกอีเมลที่มีในระบบ และกดส่งข้อมูล
  * **Then:** ระบบแสดงข้อความ "ส่งลิงก์ไปยังอีเมลของคุณแล้ว" และมีอีเมลส่งเข้า Inbox จริง

* **Scenario 2: ลิงก์หมดอายุ**
  * **Given:** ผู้ใช้ได้รับลิงก์รีเซ็ตรหัสผ่าน
  * **When:** ผู้ใช้กดลิงก์นั้นหลังจากเวลาผ่านไป 20 นาที
  * **Then:** ระบบแสดงหน้าต่าง Error "ลิงก์หมดอายุ กรุณาทำรายการใหม่" และไม่ยอมให้เปลี่ยนรหัส

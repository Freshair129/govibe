metadata ตาม system prompt

**Impact to:** 

---

## 1. Context (บริบทและปัญหา)
[อธิบายว่าตอนนี้เรากำลังเจอปัญหาอะไร หรือทำไมเราถึงต้องทำการตัดสินใจในเรื่องนี้ อธิบายข้อจำกัดทางเทคนิค หรือความต้องการทางธุรกิจที่มีผลต่อการตัดสินใจ]

## 2. Decision (การตัดสินใจ)
[ระบุอย่างชัดเจนว่า "เราตัดสินใจเลือกอะไร" และอาจเสริมด้วยเหตุผลหลักสั้นๆ]

## 3. Alternatives Considered (ทางเลือกอื่นที่นำมาพิจารณา)
[ระบุทางเลือกอื่นๆ ที่เราหยิบมาเทียบ และเหตุผลว่าทำไมถึง **"ไม่เลือก"** ทางเลือกเหล่านั้น]
* **Option A:** [ชื่อทางเลือก] - [ทำไมถึงไม่เลือก เช่น ราคาแพงไป, ทีมไม่คุ้นเคย]
* **Option B:** [ชื่อทางเลือก] - [ทำไมถึงไม่เลือก]

## 4. Consequences (ผลกระทบที่ตามมา)
[ผลลัพธ์ที่จะเกิดขึ้นหลังจากการตัดสินใจนี้ มีทั้งข้อดีและข้อเสีย]

**Impact to:** `code`,`docs`,`tests`
* **Positive:**
  * [เช่น ลดเวลาในการ Setup โปรเจกต์ลง 50%]
  * [เช่น โค้ดอ่านง่ายขึ้นและ Test ง่ายขึ้น]

* **Negative:**
  * [เช่น ต้องใช้เวลาเทรนทีมใหม่ประมาณ 1 สัปดาห์]
  * [เช่น ไฟล์ Bundle size อาจจะใหญ่ขึ้น 10kb]

Phase 0

Feasibility Spike — พิสูจน์ความเสถียร

Duration: 1 week
0%

ก่อนเริ่ม Sprint จริง ต้องพิสูจน์ให้ได้ว่าระบบ YouTube IFrame API ทำงานร่วมกับ WebSocket sync ในการดึงพิกัดเวลาของเพลงได้เสถียรบนมือถือ 2 เครื่อง และหาข้อจำกัดระบบ

Phase 1

MVP Core — ฟังก์ชันห้องและการแชร์เพลง

Duration: 4 weeks
0%

วางรากฐานโครงสร้างระบบ Client และ Server ให้ Rider สามารถเปิดห้องและส่งต่อลิงก์ห้องให้ Passenger ร่วมใช้งานได้จริงบนระบบ Production

Phase 2

Sync Calibration — จูนนิ่งความตรงระดับเสี้ยววิ

Duration: 3 weeks
0%

จูนนิ่งระดับความเสถียรระหว่าง Rider-Passenger และแก้สภาวะ Autoplay บล็อก หรือแอปหลับขณะปิดหน้าจอขับขี่จริง

Phase 3

Beta Test & rider feedback — นำทางจริงบนบอร์ด

Duration: 2 weeks
0%

รวบรวม Bugs และดึง Feedback จริงมาประเมินผลความเสถียรของเครื่องเล่น YouTube ซิงค์ และระบบเสียง

Phase 4

Future Backlog — ส่วนเสริมอนาคต

Duration: Future
0%
